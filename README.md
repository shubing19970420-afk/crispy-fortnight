# 一杆归洞

原创二维俯视角高尔夫解谜，三关最小可玩原型。Vite + TypeScript + Canvas，无后端、无外部美术或运行时 CDN 依赖。

## 打开试玩

安装 Node.js 22.12+（或 20.19+），在项目目录打开终端：

```sh
npm ci
npm run dev
```

用浏览器打开终端显示的本地地址（通常是 http://localhost:5173）。不要直接双击 index.html。手机与电脑处于同一局域网时，可打开终端显示的 Network 地址。

云开发环境中先运行 `cd /workspace/crispy-fortnight && npm run dev`，再使用开发工具提供的 5173 端口转发功能；如果工具没有转发功能，请下载项目到本机运行。

## 操作

点击关卡卡片进入。按住白球向击球方向的反方向拖拽，松手击球；拉得越远力度越大，150 个球场单位达到最大力度。虚线指向发射方向，橙线表示拉杆方向，底部显示力度。拖拽不到 6 单位会取消击球。支持鼠标和触屏。

球运动期间不能再次击球；低速进入洞口成功，停在洞外失败。四边为实体桌沿，可反弹，正常布局没有开放的出界缺口；物理引擎仍处理异常越界失败。失败可立即重试。R 重新开始，Esc 返回选关。进度只保存在当前浏览器，可在禁用存储时正常玩。

## 检查与提交

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署的静态网站，可上传至支持静态站点的网站托管服务。使用 HTTP 服务器访问。浏览器端回归：先运行 `npm test` 生成解，再启动开发服务器，执行 `node tests/browser.mjs`；默认使用 `/usr/bin/chromium`，其他安装位置设置 `CHROMIUM_PATH`。

## 结构

- `src/levels.ts`：三关名称、起点、洞口和固定矩形障碍。
- `src/physics.ts`：固定 240Hz 步长、线性滚动阻力、圆与矩形碰撞、反弹损耗、单次击球状态与低速入洞。
- `src/main.ts`：Canvas 绘制、拖拽、选关、结果与本地进度。
- `src/style.css`：响应式临时美术与布局。
- `tests/physics.test.ts`：搜索每关解，并验证碰撞、输入锁定与成功失败条件。
- `tests/browser.mjs`：真实浏览器拖拽、通关、下一关、失败、重试、移动端布局验证。

## 设计边界与后续

当前只有三关，预计首次体验 5–10 分钟，尚未达到最终作业 30 分钟以上的目标。没有完整反弹预览、移动障碍、道具或额外机制。所有场景均由代码绘制，表达借鉴日常空间成为球场，布局与素材原创。

后续可仅通过新增布局、尺度与力量容错组合扩展关卡；先安排试玩记录完成时间，再决定关卡数量，避免仅靠增加难度拖长体验。最终截止为 10 月 19 日 23:59，当前阶段保持三关范围。

开发解（球场坐标）：第一关向右，拖拽长度约 55.6；第二关从球向左下拖约 (47, 62)；第三关向左下拖约 (50.3, 61.4)。第二、三关均可一次上沿反弹归洞。仅供调试或卡关时参考。
